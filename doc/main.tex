\section{Introducción}
\label{sec:introduccion}

El análisis de datos en el ámbito de la salud desempeña un papel fundamental en la toma de decisiones y la optimización de recursos. En particular, las Unidades de Cuidados Intensivos (UCI) manejan grandes volúmenes de información clínica que, si se analiza adecuadamente, puede proporcionar información clave sobre el desempeño de los tratamientos, la administración de recursos y la atención al paciente. En este contexto, los sistemas de análisis multidimensional, como los cubos OLAP, ofrecen una manera eficaz de estructurar y explorar estos datos para obtener información valiosa.
\\

El presente trabajo consiste en el desarrollo de un informe interactivo basado en Power BI, utilizando como fuente de datos el almacén de datos desarrollado previamente para el proyecto denominado "\textbf{Cubo UCI}". Este cubo multidimensional contiene información sobre las Unidades de Cuidados Intensivos (UCI), incluyendo datos relacionados con tratamientos, volumen de fluido suministrado, cantidad administrada y otros aspectos relevantes para su análisis.







\section{Objetivos}
\label{sec:objetivos}

El objetivo principal de este informe es proporcionar una visualización comprensible y efectiva de los datos, permitiendo analizar información clave mediante gráficos, tablas y otros elementos visuales. Para ello, se ha utilizado Power BI como herramienta de desarrollo, aprovechando su capacidad de conexión con modelos multidimensionales y consultas MDX para extraer y validar los datos necesarios. Cada elemento visual del informe está respaldado por una consulta MDX que asegura la correspondencia entre los datos del cubo y la información presentada.
\\

Este objetivo se puede separar en los siguientes más específicos:

\begin{itemize}
	\item Desarrollar un informe interactivo utilizando Power BI que permita analizar los datos del proyecto Cubo UCI.
	\item Implementar gráficos, tablas y elementos visuales que representen correctamente la información contenida en el almacén de datos, facilitando la comprensión de los datos por parte del usuario final.
	\item Validar los datos presentados en el informe mediante consultas MDX, asegurando que los resultados coincidan con los valores obtenidos directamente del cubo multidimensional.
	\item Aplicar un diseño visual claro y profesional para que el informe cumpla con los estándares de visualización de datos.
	\item Documentar el proceso de desarrollo del informe, incluyendo capturas, explicaciones de los elementos visuales y el código MDX utilizado en cada caso.
\end{itemize}

\subsubsection{Consulta 1}

Con el propósito de garantizar la validez y coherencia de los resultados obtenidos, se ha diseñado la siguiente consulta \textbf{MDX}, que permite corroborar los datos generados y asegurar que cumplen con las expectativas del proyecto.  

\begin{lstlisting}[style=ddlstyle, label=lst:consulta1,caption=Consulta 1: Gasto en Volumen VS Cantidad por tratamiento realizado]


SELECT
	{
		[Measures].[Volumen Fluido],
		[Measures].[Cantidad]
	} ON COLUMNS,
	NONEMPTY(
		[Tratamiento].[Nombre Tratamiento].Children
	) ON ROWS
FROM 
	[UCIDW]

\end{lstlisting}

\subsubsection{Consulta 2}

Para asegurar la fiabilidad y coherencia de los resultados obtenidos, se ha creado la siguiente consulta \textbf{MDX}, que permite validar los datos generados y confirmar que cumplen con los objetivos del proyecto. 

\begin{lstlisting}[style=ddlstyle, label=lst:consulta2,caption=Consulta 2: Cantidad de medicamento suministrado por año]
	
	

WITH 
	MEMBER [Anyo].[Jerarquia].[Total] AS 
	AGGREGATE(
	[Anyo].[Jerarquia].[Anyo].Members
	)
SELECT
	[Measures].[Cantidad] ON COLUMNS,
	{
		nonempty([Anyo].[Jerarquia].[Anyo].Members),
	[Anyo].[Jerarquia].[Total]
	} ON ROWS
FROM
	[UCIDW]
	
\end{lstlisting}
